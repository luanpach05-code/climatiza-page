# ❄️ Climatiza Page

Landing Page desenvolvida para a empresa Climatiza, especializada em instalação, manutenção e higienização de aparelhos de ar-condicionado.

O projeto foi criado com foco em apresentar os serviços da empresa, destacar seus diferenciais e facilitar o contato com potenciais clientes por meio de uma interface moderna, responsiva e intuitiva.

## 🚀 Demonstração

Acesse o projeto online:

https://luanpach05-code.github.io/climatiza-page/

## ✨ Funcionalidades

* Apresentação da empresa
* Exibição dos serviços oferecidos
* Design moderno e profissional
* Layout responsivo
* Botão de contato
* Navegação simples e intuitiva

## 🛠️ Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript

## 📚 Aprendizados

Durante o desenvolvimento deste projeto foram praticados conceitos de:

* Estruturação semântica com HTML
* Flexbox e posicionamento de elementos
* Responsividade para diferentes dispositivos
* Estilização avançada com CSS
